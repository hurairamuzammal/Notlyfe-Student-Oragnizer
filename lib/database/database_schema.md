# Notlyfe Database Schema

This document outlines the database schema for the Notlyfe app. It includes table structures for both SQLite (local storage) and Supabase (cloud storage), as well as Row Level Security (RLS) policies.

## Supabase Tables

### courses

This table stores user courses.

| Column Name | Data Type | Description | Constraints |
|------------|-----------|-------------|------------|
| id | bigint | Unique identifier for the course | Primary Key, Generated by default as identity |
| created_at | timestamptz | When the course was created | Not Null, Default: now() |
| user_id | uuid | ID of the user who owns the course | Default: auth.uid() |
| title | text | Title of the course | Nullable |
| color | text | Color of the course card (hex format) | Nullable |
| image | text | Path to the course image asset | Nullable |
| is_synced | boolean | Whether the course is synced | Default: false |

### notes

This table stores user notes with optional course associations.

| Column Name | Data Type | Description | Constraints |
|------------|-----------|-------------|------------|
| id | text | Unique identifier for the note (UUID string) | Primary Key |
| user_id | text | ID of the user who created the note | Not Null |
| title | text | Title of the note | Not Null |
| content | text | Content of the note | Not Null |
| created_at | text | ISO 8601 creation timestamp string | Not Null |
| updated_at | text | ISO 8601 update timestamp string | Not Null |
| course_id | text | ID of the associated course (if any) | Nullable |
| is_synced | integer | Sync status flag | Not Null, Default: 0 |

### todo

This table stores user todo items and reminders.

| Column Name | Data Type | Description | Constraints |
|------------|-----------|-------------|------------|
| id | bigint | Unique identifier for the todo | Primary Key, Generated by default as identity |
| created_at | timestamptz | When the todo was created | Not Null, Default: now() |
| content | text | Description of the task | Nullable |
| reminder_at | timestamp | Scheduled reminder timestamp | Default: now() |
| alert | boolean | Whether alert notification is enabled | Default: false |
| status | boolean | Completed status | Default: false |
| user_id | uuid | Owner user ID | Default: auth.uid() |

### user_files

This table tracks files uploaded by users to Supabase storage.

| Column Name | Data Type | Description | Constraints |
|------------|-----------|-------------|------------|
| id | bigint | Unique identifier for the file metadata record | Primary Key, Generated by default as identity |
| created_at | timestamptz | When the record was created | Not Null, Default: now() |
| user_id | uuid | Owner user ID | Default: auth.uid() |
| course_id | text | Associated course ID | Nullable |
| file_path | text | Public/signed storage URL | Nullable |
| file_type | text | MIME type of the file | Nullable |
| file_name | text | Original file name | Default: 'Unknown' |
| file_size | numeric | Size of the file in bytes | Nullable |

### user_profile

This table stores user profile information.

| Column Name | Data Type | Description | Constraints |
|------------|-----------|-------------|------------|
| user_id | uuid | ID of the user | Primary Key, Default: auth.uid() |
| created_at | timestamptz | Profile creation timestamp | Not Null, Default: now() |
| full_name | text | Full name of the user | Nullable |

## Security Rules & Row Level Security (RLS) Policies

All public tables have Row Level Security enabled (`ALTER TABLE ... ENABLE ROW LEVEL SECURITY;`). Each user can only access, create, update, or delete their own data.

### 1. `courses` Table Policies
```sql
ALTER TABLE public.courses ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Users can view own courses"
ON public.courses FOR SELECT TO authenticated
USING ((select auth.uid()) = user_id);

CREATE POLICY "Users can insert own courses"
ON public.courses FOR INSERT TO authenticated
WITH CHECK ((select auth.uid()) = user_id);

CREATE POLICY "Users can update own courses"
ON public.courses FOR UPDATE TO authenticated
USING ((select auth.uid()) = user_id)
WITH CHECK ((select auth.uid()) = user_id);

CREATE POLICY "Users can delete own courses"
ON public.courses FOR DELETE TO authenticated
USING ((select auth.uid()) = user_id);
```

### 5. `user_profile` Table Policies & Auto-creation Trigger
```sql
ALTER TABLE public.user_profile ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Users can view own profile"
ON public.user_profile FOR SELECT TO authenticated
USING ((select auth.uid()) = user_id);

CREATE POLICY "Users can insert own profile"
ON public.user_profile FOR INSERT TO authenticated
WITH CHECK ((select auth.uid()) = user_id);

CREATE POLICY "Users can update own profile"
ON public.user_profile FOR UPDATE TO authenticated
USING ((select auth.uid()) = user_id)
WITH CHECK ((select auth.uid()) = user_id);

CREATE POLICY "Users can delete own profile"
ON public.user_profile FOR DELETE TO authenticated
USING ((select auth.uid()) = user_id);

-- Trigger to automatically create a profile record when a user signs up
CREATE OR REPLACE FUNCTION public.handle_new_user()
RETURNS trigger AS $$
BEGIN
  INSERT INTO public.user_profile (user_id, full_name)
  VALUES (new.id, COALESCE(new.raw_user_meta_data->>'full_name', ''))
  ON CONFLICT (user_id) DO UPDATE
  SET full_name = EXCLUDED.full_name
  WHERE public.user_profile.full_name IS NULL OR public.user_profile.full_name = '' OR public.user_profile.full_name = 'Anonymous';
  RETURN NEW;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

DROP TRIGGER IF EXISTS on_auth_user_created ON auth.users;
CREATE TRIGGER on_auth_user_created
  AFTER INSERT ON auth.users
  FOR EACH ROW EXECUTE FUNCTION public.handle_new_user();
```

### 6. Storage (`uploaded_files` bucket) Policies
Storage objects are restricted by folder matching the authenticated user's ID (`public/<user_id>/...` or `<user_id>/...`):
```sql
CREATE POLICY "Users can view own storage objects"
ON storage.objects FOR SELECT TO authenticated
USING (
  bucket_id = 'uploaded_files' AND (
    (auth.uid())::text = (storage.foldername(name))[1]
    OR
    ((storage.foldername(name))[1] = 'public' AND (auth.uid())::text = (storage.foldername(name))[2])
  )
);

CREATE POLICY "Users can upload own storage objects"
ON storage.objects FOR INSERT TO authenticated
WITH CHECK (
  bucket_id = 'uploaded_files' AND (
    (auth.uid())::text = (storage.foldername(name))[1]
    OR
    ((storage.foldername(name))[1] = 'public' AND (auth.uid())::text = (storage.foldername(name))[2])
  )
);

CREATE POLICY "Users can update own storage objects"
ON storage.objects FOR UPDATE TO authenticated
USING (
  bucket_id = 'uploaded_files' AND (
    (auth.uid())::text = (storage.foldername(name))[1]
    OR
    ((storage.foldername(name))[1] = 'public' AND (auth.uid())::text = (storage.foldername(name))[2])
  )
)
WITH CHECK (
  bucket_id = 'uploaded_files' AND (
    (auth.uid())::text = (storage.foldername(name))[1]
    OR
    ((storage.foldername(name))[1] = 'public' AND (auth.uid())::text = (storage.foldername(name))[2])
  )
);

CREATE POLICY "Users can delete own storage objects"
ON storage.objects FOR DELETE TO authenticated
USING (
  bucket_id = 'uploaded_files' AND (
    (auth.uid())::text = (storage.foldername(name))[1]
    OR
    ((storage.foldername(name))[1] = 'public' AND (auth.uid())::text = (storage.foldername(name))[2])
  )
);
```
